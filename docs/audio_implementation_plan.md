# [구현 계획서] 8-Game BGM(배경음악) 및 볼륨 제어 시스템

게임 플레이 아레나(`play.html`)에 오락실 레트로 감성의 **배경음악(BGM)**과 **상단 볼륨 ON/OFF 토글 스위치**를 구축합니다.
기존 8종 게임 로직과 3D 회전문, 순위표 시스템은 **단 1글자도 변경 없이 100% 원형 보존**하며, 독립 모듈(`audioManager.js`) 방식으로 안전하게 연동합니다.

---

## 1. 핵심 안전 및 사용자 경험 원칙

1. **기존 게임 로직 완벽 보존**:
   - `script.js`와 `leaderboard.js`의 기존 알고리즘은 그대로 유지됩니다.
2. **독립 오디오 매니저 (`audioManager.js`)**:
   - 음원 로딩, 무한 반복(Loop) 재생, 페이드인, 음소거 토글 등 오디오와 관련된 모든 기능은 새 파일 `audioManager.js`가 전담합니다.
3. **브라우저 자동 재생 정책(Autoplay Policy) 완벽 대응**:
   - 현대 브라우저는 첫 사용자 클릭 전 소리 재생을 차단하므로, 페이지 진입 후 첫 화면 클릭 또는 게임 시작 시 자연스럽게 소리가 켜지도록 방어 설계합니다.
4. **상단 볼륨 ON/OFF 스위치 & 사용자 설정 기억**:
   - 우측 상단에 🔊 `[ 🎵 BGM ON ]` / 🔇 `[ 🔇 BGM OFF ]` 토글 버튼을 제공합니다.
   - 사용자가 소리를 꺼두면 브라우저 저장소(`localStorage`)에 저장하여 다음 방문 시에도 음소거 상태를 기억합니다.
5. **편안한 볼륨 레벨 (30%)**:
   - 게임 플레이에 방해되지 않는 잔잔하고 기분 좋은 볼륨 크기로 자동 튜닝합니다.

## 2. 게임별 BGM 무드 매칭 (4가지 레트로 테마)

| 음원 파일명 | 음악 스타일 | 어울리는 게임 |
| :--- | :--- | :--- |
| `bgm_arcade_rush.wav` | 빠르고 신나는 8비트 아케이드 비트 | 👆 **스피드 연타**, 🐹 **두더지 잡기** |
| `bgm_tension_loop.wav` | 째깍째깍 긴장감 넘치는 비트 | ⏱ **반응 속도 측정** |
| `bgm_puzzle_cozy.wav` | 귀엽고 차분한 멜로디의 퍼즐 BGM | 🧠 **카드 짝 맞추기**, ✕◯ **틱택토**, ⇅ **업다운** |
| `bgm_retro_game.wav` | 경쾌하고 즐거운 레트로 게임 멜로디 | 🎲 **주사위 대결**, ✌️ **가위바위보** |

* 외부 다운로드 링크의 저작권/품질 문제를 방지하기 위해, 파이썬 신디사이징 기술을 통해 잡음 없이 깔끔하고 쾌활한 100% 저작권 프리 8비트 레트로 칩튠 루프를 직접 생성하여 `assets/audio/`에 탑재합니다.

## 3. UI 디자인 및 배치

* **위치**: `play.html`의 상단 네비게이션 바 우측 (`← 홈(회전문)으로 돌아가기` 옆)
* **외형**: 둥근 알약(Pill) 형태의 세련된 토글 버튼
  - 켜짐 상태: `🎵 BGM ON` (은은한 다크 테두리 & 스피커 아이콘)
  - 꺼짐 상태: `🔇 BGM OFF` (차분한 회색 톤)
